Editor

Shows the configured policy file. Validation and simulation use this candidate, not the running policy. Admin UI access is never affected by policies; S3 clients can still be locked out, so validate and simulate before saving.

Simulate a request

Use a Pithos operation such as GetObject (not s3:GetObject). Leave account and principal empty for an anonymous request. The access key is optional and controls Lua isAnonymous and access-key predicates. No object, tags or HTTP context is supplied, so context-dependent results are not a guarantee of live access. Lua runs are limited to one million VM instructions.
